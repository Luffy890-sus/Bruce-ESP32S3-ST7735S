# Подключение: питание, экран, кнопки, модули

Все провода — для модуля **ESP32-S3-N16R8** и дисплея **ST7735S 128×160**.

> Если вы собираете устройство целиком (плата + экран + 3 кнопки + CC1101 + LiPo
> с зарядкой), начните со сводной [инструкции по подключению](SETUP_GUIDE.md) —
> там порядок сборки, BOM и чек-лист первого включения.
> Эта страница — справочник по отдельным узлам.

---

## 1. Питание

### Вариант A — от USB (отладка, рекомендуемый)

Питать от USB-C порта платы, который выведен на мост **CH343**.

```
USB-C (плата) ──> ПК / повербанк 5 V
```

* Потребление со включённой подсветкой: **~120–180 мА** (0.6–0.9 Вт).
* Обычный USB 2.0 порт (500 мА) — с запасом.
* **Обязательно** общий провод: при питании от одного источника и отладке от другого
  без общего GND CH343 не увидит логи.

### Вариант B — от аккумулятора LiPo 3.7 V (автономная сборка)

На самой плате ESP32-S3-N16R8 **нет charge-модуля**, поэтому нужен внешний
DC-DC повышающий преобразователь до 3.3 V.

```
LiPo 3.7V ──> TP4056 (заряд, 1A) ──> MT3608 / ME2108A33 (Boost → 3.3V) ──> 3V3 платы
                                                                    └──> GND платы
```

| Блок | Что выбрать | Комментарий |
|---|---|---|
| Зарядник | TP4056 + защита DW01 | ток заряда 1 kΩ → ~1000 мА |
| Преобразователь | **только 3.3 V**, не 5 V | ESP32-S3 толерантен к 5 V на 3V3 **нет** |
| Кондёнсер | 100–220 мкФ на выходе 3.3 V | гасит просадку при старте Wi-Fi |
| Аккумулятор | LiPo 3.7 V, 500–2000 мА·ч | ~3–5 ч работы с подсветкой |

### Проверка перед первой прошивкой

| Контрольная точка | Ожидается |
|---|---|
| 3V3 → GND | 3.25–3.35 V |
| 5V → GND (если есть) | 4.8–5.2 V |
| 3V3 при включённом Wi-Fi | не проседает ниже 3.1 V |

Просадка ниже 3.0 V → сброс по brownout (`Brownout detector was triggered`).
Лечится более короткими/толстыми проводами и конденсатором.

> **Никогда не подавайте 5 V на `3V3`, на `BL` дисплея или на ноги кнопок.**
> Дисплей ST7735S питается строго 3.3 V.

## 2. Дисплей ST7735S 128×160

4-проводной SPI (без чтения MISO). **Пиновые номера взяты с шелкографии платы —
не путать с общим SPI для радиомодулей, это отдельная шина дисплея.**

```
Плата (подпись)             ST7735S 128x160
-----------------           ----------------
GPIO11  (Display SDA) ────►  SDA / MOSI / SDI
GPIO12  (Display SCL) ────►  SCL / CLK
GPIO46  (Display CS)  ────►  CS
GPIO9   (Display DC)  ────►  DC / RS / A0
GPIO10  (Display RES) ────►  RES / RST
GPIO3   (Display BLK) ────►  LED / BLK / backlight
3V3                     ────►  VCC
GND                     ────►  GND
```

### Нумерация ног модуля ST7735S (8-pin шлейф)

| # | Нога | Куда |
|---|---|---|
| 1 | GND | GND |
| 2 | VCC | 3V3 |
| 3 | SCL/CLK | GPIO12 |
| 4 | SDA/SDI | GPIO11 |
| 5 | A0/DC | GPIO9 |
| 6 | RES/RST | GPIO10 |
| 7 | CS | GPIO46 |
| 8 | LED/BLK | GPIO3 (через резистор 10–100 Ω, если нога подписана `LED+`) |

> Если подсветка не включается, а нога `LED` подписана как `LED+`/без резистора —
> поставьте последовательно 33–100 Ω. Если подсветка горит всегда и не гаснет —
> в профиле `_setBrightness()` намеренно no-op, яркость фиксированная.

> ⚠️ **GPIO3 — strapping-пин ESP32-S3** (выбор источника кода загрузки). Если дисплей
> тянет его в единицу при сбросе, плата может не войти в download mode. Признак:
> `Connecting........_____` без `Chip sync`. Лечится удержанием BOOT при сбросе.

### Параметры в сборке

Задаются build-флагами в `boards/esp32s3-n16r8-st7735s.ini`:

```ini
-DST7735_DRIVER
-DST7735_REDTAB          ; цветовая таблица redtab
-DTFT_RGB_ORDER=TFT_BGR
-DTFT_WIDTH=128
-DTFT_HEIGHT=160
-DROTATION=1             ; 160x128 ландшафт
-DSPI_FREQUENCY=27000000
```

Если цвета инвертированы (синий ↔ красный) — поменяйте `TFT_BGR` на `TFT_RGB`.
Если изображение смещено на 1–2 пикселя, у ST7735S это обычно вариант панели
(`REDTAB` / `BLACKTAB` / `GREENTAB`) — меняется тем же флагом.

## 3. Три кнопки

```
GPIO21 (LEFT)   ──┤ ├──┐        UP
                  кнопка
GND         ───────────┘

GPIO48 (SELECT) ──┤ ├──┐        SEL (OK / ESC долго)
                  кнопка
GND         ───────────┘

GPIO47 (RIGHT)  ──┤ ├──┐        DOWN
                  кнопка
GND         ───────────┘
```

* Внутренние **pull-up** включаются прошивкой (`pinMode(..., INPUT_PULLUP)`).
* Внешние резисторы **не нужны**.
* Кнопки — обычные тактовые, замыкают на **GND**, без блокировки.
* Дребезг гасится программно, 120 мс.
* Это те же ноги, что на плате подписаны `LEFT / SELECT / RIGHT` (вход в
  `Encoder SW` не используется — энкодер в этом профиле выключен).

Подробная карта нажатий — [BUTTONS.md](BUTTONS.md).

## 4. Внешние модули

### Discreet RF (Sub-GHz) — CC1101

Подключается **своей отдельной** SPI-шиной (не шиной дисплея и не SD):

| Сигнал CC1101 | Подпись на плате | GPIO |
|---|---|---|
| MISO | CC1101 MISO | GPIO8 |
| MOSI | CC1101 MOSI | GPIO17 |
| SCK | CC1101 SCK | GPIO18 |
| CSN | CC1101 CSN | GPIO15 |
| GDO0 | CC1101 GDO0 | GPIO16 |
| GDO2 | CC1101 GDO2 | GPIO6 |
| VCC | — | 3V3 (**не 5 V**) |
| GND | — | GND |

### SD-карта (SPI)

| Сигнал | Подпись на плате | GPIO |
|---|---|---|
| MISO | SD MISO | GPIO19 |
| SCK | SD SCK | GPIO20 |
| MOSI | SD MOSI | GPIO41 |
| CS | SD CS | GPIO42 |

### Прочие узлы платы

| Узел | Подпись на плате | GPIO |
|---|---|---|
| I²C (PN532 / RFID / BAT ADC) | SCL / SDA | GPIO1 / GPIO2 |
| IR TX / IR RX | IR TX / IR RX | GPIO5 / GPIO4 |
| GPS (UART2) | ESP TX / ESP RX | GPIO40 / GPIO39 |
| Отладочный UART0 | RXD0 / TXD0 (CH343) | GPIO44 / GPIO43 |

### Куда нельзя подключаться

| GPIO | Причина |
|---|---|
| **GPIO26 … GPIO32** | SPI flash (16 МБ) — любое использование рвёт прошивку |
| **GPIO33 … GPIO37** | octal PSRAM (R8) — заняты, трогать нельзя |
| GPIO36, 37, 38 | если бы не PSRAM, были бы единственными «безопасными» — **в N16R8 заняты** |
| GPIO19 … GPIO47 | заняты платными узлами (см. таблицы выше), свободны только при отказе от них |

> Именно поэтому в этом профиле **NRF24 выключен** (`NRF24_* = -1`): штатные ноги
> nRF24 у таких плат попадают на GPIO35–38, то есть на PSRAM.

## 5. Отладочный UART

| Сигнал | GPIO |
|---|---|
| UART0 TX | GPIO43 (подпись `TXD0`) |
| UART0 RX | GPIO44 (подпись `RXD0`) |

`Serial` в прошивке = **UART0** = мост CH343 = ваш COM-порт, 115200 8N1.
Логи видны сразу после сброса платы кнопкой RESET (или повторным открытием порта).

> В профиле выставлено `ARDUINO_USB_MODE=0`, `ARDUINO_USB_CDC_ON_BOOT` отключён —
> иначе `Serial` уходил бы в native USB (GPIO19/20), и COM-порт молчал бы.
> Побочный эффект: **BadUSB/DFU в этом профиле не работают**.
