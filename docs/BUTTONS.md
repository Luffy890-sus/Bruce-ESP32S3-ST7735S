# Управление тремя кнопками

Прошивка опрашивает кнопки в отдельной задаче `InputHandler` с периодом 10 мс.
Дребезг гасится фронтовым детектором с окном **120 мс**, долгое нажатие — **700 мс**.

## Раскладка

```
        [ UP ]
          |
   [ SEL ]   [ DOWN ]
```

| Кнопка | GPIO | Короткое нажатие | Долгое нажатие (>700 мс) |
|---|---|---|---|
| **UP** | GPIO5 | Перейти к предыдущему пункту меню | — |
| **SEL** | GPIO4 | **ОК** — открыть/подтвердить | **ESC / НАЗАД** — выход из меню |
| **DOWN** | GPIO6 | Перейти к следующему пункту меню | — |

## Как это работает внутри

`InputHandler()` в `boards/esp32s3-n16r8-st7735s_board/interface.cpp` выставляет
флаги Bruce, которые потребляет меню (`src/core/display.cpp`):

| Кнопка | Выставляемые флаги |
|---|---|
| UP | `UpPress`, `PrevPress`, `AnyKeyPress` |
| DOWN | `DownPress`, `NextPress`, `AnyKeyPress` |
| SEL (коротко) | `SelPress`, `AnyKeyPress` |
| SEL (долго) | `EscPress`, `AnyKeyPress` |

Меню трактует их так:

* `check(UpPress)` / `PrevPress` — шаг вверх по списку;
* `check(DownPress)` / `NextPress` — шаг вниз;
* `check(SelPress)` — выбрать пункт;
* `check(EscPress)` — выход на уровень вверх (игнорируется в главном меню).

Подпись кнопки подтверждения на экране берётся из `-DBTN_ALIAS='"OK"'`.

## Сценарии

### Навигация по меню

```
DOWN DOWN DOWN     -> спуститься на 3 пункта
SEL                -> открыть выбранный пункт
SEL (долго)        -> вернуться назад
UP                 -> подняться на пункт
```

### Экран блокировки / boot-password

`DOWN` переключает символы, `SEL` подтверждает. Пароль по умолчанию отсутствует.

### Спящий режим экрана

Экран гаснет по таймауту (`DimScreen`, настройки в `Settings → Display`).
Любое нажатие кнопки будит дисплей.

### Отключение

Профиль платы **не управляет питанием**, поэтому выключение — это либо
`Settings → Reboot`, либо физическое отключение питания/USB.

## Смена пинов кнопок

Пины задаются build-флагами в `boards/esp32s3-n16r8-st7735s.ini`:

```ini
    -DUP_BTN=5
    -DSEL_BTN=4
    -DDW_BTN=6
    -DBTN_ALIAS='"OK"'
```

Можно и без правки `.ini` — значения в `interface.cpp` защищены `#ifndef`, поэтому
достаточно добавить свои `-D...` позже по списку `build_flags`.

### Активный уровень

Кнопки замыкают GPIO на **GND**, поэтому активный уровень — `LOW`.
Если схема с обратным включением (через резистор на 3V3), переопределите:

```ini
    -DBTN_ACTIVE=1      ; HIGH
```

### Пороги

```ini
    -DBTN_DEBOUNCE_MS=120
    -DBTN_LONGPRESS_MS=700
```

## Чего намеренно нет

* **Нет long-press на UP/DOWN.** Bruce в ветке без `HAS_KEYBOARD` ждёт удержания
  `PrevPress` для «долгого вверх», но наш обработчик работает по фронту, а не по
  уровню. Для выхода из меню используйте долгое нажатие **SEL**.
* **Нет отдельной кнопки ESC.** ESC совмещён с SEL (long press) — стандартная
  схема для трёхкнопочных портов.
* **Нет power-off / deep sleep** — нет соответствующей обвязки на плате.
