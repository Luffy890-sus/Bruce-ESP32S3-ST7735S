# Инструкция по подключению — полная сборка

Состав: **ESP32-S3-N16R8** + **ST7735S 128×160** + **3 кнопки** + **CC1101 (433 МГц)**
+ **питание от LiPo с зарядкой**.

> ⚠️ **Распиновка на фото из карточки товара — от другой платы.**
> Там `nRF24` висит на GPIO35/36/37/38, `Display CS=46`, `SCK=12`.
> Для **ESP32-S3-N16R8** это **неприменимо**: GPIO26–32 заняты flash,
> GPIO33–37 заняты octal PSRAM. Ниже — распиновка, которая реально работает
> на вашей плате и уже прошита.

**Почему нельзя питать напрямую от LiPo:** у ESP32-S3 абсолютный максимум

Повышающий преобразователь на 3.3 В обязателен.

## 2. Общая схема

```
                     ┌──────────────┐
   LiPo 3.7V  ───────┤  TP4056 (B+,B−)
   (SW)  ────────────┤ заряд + защита
                     └──────┬───────┘
                       OUT+ │ OUT−(GND)
                            │
                     ┌──────┴───────┐
                     │ Boost 3.3V   │   100µF на выходе
                     │ (MT3608)     │
                     └──────┬───────┘
                    3V3 ────┼──────────────┬──────────────┬───────────┐
                    GND ────┼──────────────┼──────────────┼───────────┤
                            │              │              │           │
                    ┌───────┴──────┐  ┌────┴─────┐  ┌─────┴────┐ ┌────┴────┐
                    │  ESP32-S3    │  │ ST7735S  │  │ CC1101   │ │ 3 кнопки│
                    │  N16R8       │  │ 128x160  │  │ 433 MHz  │ │         │
                    └──────────────┘  └──────────┘  └──────────┘ └─────────┘
                            │
                     CH343 USB-C  (прошивка + логи)
```

## 3. Питание и зарядка

### 3.1 Подключение TP4056

```
LiPo +  ────> B+          TP4056          OUT+  ────> VIN boost-преобразователя
LiPo −  ────> B−          (B+,B−)         OUT−  ────> GND boost / общая земля
                        (DW01 защита)
USB 5V  ────> IN+ / IN−  (заряд от сети)
```

* Красный светодиод — идёт заряд, синий — заряд окончен / защита сработала.
* Ток заряда задаётся резистором `R_PROG`: `1 kΩ` → ~1000 мА, `2 kΩ` → ~500 мА.
  Для LiPo 1000 мА·ч ставьте 2 kΩ (0.5C).
* **Обязательно берите версию с 4 контактами** (`B+ B− OUT+ OUT−`) — в ней есть
  защита от глубокого разряда и КЗ. Версия с 2 контактами battery-only не защищает.

### 3.2 Повышающий преобразователь

**Вариант A — ME2108A33 / XCL103 (фиксированные 3.3 В) — рекомендую.**
Ничего подстраивать не нужно, просто припаять.

**Вариант B — MT3608 (регулируемый). Порядок настройки ОБЯЗАТЕЛЕН:**

1. **До** подключения платы крутить подстроечник мультиметром на выходе,
   пока не получите **3.30 V** (±0.05).
2. Только потом подключать ESP32-S3.

> Подключить неподстроенный MT3608 (у него на борту может быть 5–9 В) —
> гарантированно сжечь ESP32-S3 и подсветку дисплея.

### 3.3 Ёмкости и защита

```
Boost OUT+ ──┬──── 100 мкФ/10 В ──── GND     (рядом с платой ESP32)
             └────> 3V3 платы
```

* **100 мкФ** обязателен: при старте Wi-Fi ESP32-S3 ест до 350 мА короткими
  импульсами, без ёмкости будет `Brownout detector was triggered`.
* Polyfuse 500 мА — в разрыв плюса сразу после TP4056, если хотите защиту от КЗ.

### 3.4 Переключатель питания

Ставьте в **разрыв плюса** между `OUT+` boost-преобразователя и `3V3` платы.
Не в разрыв LiPo — иначе TP4056 останется без нагрузки, а защита DW01 при
полном разряде уйдёт в защиту и плата «перестанет включаться» (выход —
снова подключить USB-зарядку).

Профиль Bruce для этой платы **не умеет soft power-off и deep sleep**
(на плате нет power-обвязки), поэтому механический выключатель — единственный
способ выключить устройство.

### 3.5 Проверка мультиметром (до подключения платы)

| Точка | Ожидается |
|---|---|
| `OUT+`/`OUT−` TP4056 без нагрузки | 3.9–4.2 V (напряжение батареи) |
| выход boost, GND | **3.30 V ±0.05** |
| выход boost при подключённой плате, Wi-Fi включён | не ниже **3.10 V** |

Просадка ниже 3.0 V → короче и толще провода, больше ёмкость, или более
мощный преобразователь.

## 4. Дисплей ST7735S 128×160

```
ESP32-S3-N16R8            ST7735S
----------------          -------------
GPIO17  (MOSI)    ─────►  SDA / MOSI / SDA
GPIO18  (SCLK)    ─────►  SCK / CLK
GPIO8   (CS)      ─────►  CS
GPIO9   (DC)      ─────►  DC / RS / A0
GPIO15  (RST)     ─────►  RES / RST
GPIO21  (BL)      ─────►  LED / BLK   (через 33–100 Ω, если нога подписана LED)
3V3               ─────►  VCC
GND               ─────►  GND
```

| Сигнал | GPIO |
|---|---|
| CS | **GPIO8** |
| DC | **GPIO9** |
| RST | **GPIO15** |
| MOSI | **GPIO17** |
| SCLK | **GPIO18** |
| BL | **GPIO21** |
| VCC | 3.3 V (**не 5 V**) |

MISO дисплею не нужен. Питание строго 3.3 V.

## 5. CC1101 (Sub-GHz 433 МГц)

CC1101 висит на **общей SPI-шине** с дисплеем (MOSI/SCK/MISO), у него
собственные `CSN` и `GDO0`.

```
ESP32-S3-N16R8            CC1101
----------------          -------------
GPIO17  (MOSI)    ─────►  MOSI
GPIO19  (MISO)    ─────►  MISO
GPIO18  (SCK)     ─────►  SCK / SCLK
GPIO12            ─────►  CSN / CS / SSCN
GPIO14            ─────►  GDO0
GPIO47            ─────►  GDO2      (опционально)
3V3               ─────►  VCC
GND               ─────►  GND
```

| CC1101 | GPIO | Обязателен |
|---|---|---|
| MOSI | **GPIO17** | да |
| MISO | **GPIO19** | да |
| SCK | **GPIO18** | да |
| CSN | **GPIO12** | да |
| GDO0 | **GPIO14** | да |
| GDO2 | **GPIO47** | нет |
| VCC | 3.3 V | да |
| GND | GND | да |

### Развязка по питанию (не пропускать)

```
3V3 ──┬──┬──────────────> VCC CC1101
      │  │
     10µF 100nF
      │  │
GND ──┴──┴──────────────> GND CC1101
```

Ставить **как можно ближе** к ножкам VCC/GND модуля CC1101. Без них модуль
отдаёт ошибки `CC1101 not found` или глючит на передаче.

### Антенна

* Если модуль с **SMA** — прикрутите антенну 433 МГц (спиральная или штырь ~17 см).
* Если антенны нет — припаяйте провод **17.3 см** (λ/4 для 433.92 МГц) к площадке
  `ANT`. Для 868 МГц — 8.6 см, для 915 МГц — 8.2 см.
* **Никогда не включайте передачу (TX) без антенны** — сгорает конечный каскад CC1101.

### Включение в прошивке

Пины `CSN=12`, `GDO0=14`, `GDO2=47` уже зашиты в `pins_arduino.h` этого порта.
Осталось выбрать модуль на устройстве:

```
Меню Bruce → Sub-Ghz → RF Module → CC1101
```

Если пины подключены иначе — поправьте на устройстве:
`Settings → CC1101 Pins` (сохранится в NVS), либо пересоберите с
`-DCC1101_SS_PIN=..` / `-DCC1101_GDO0_PIN=..`.

После выбора модуля в заголовке меню Sub-GHz появится пометка `(CC1101)`.
ЕслиBruce показал `CC1101 not found` — см. раздел 8.

## 6. Три кнопки

```
GPIO5   ──┤ ├──── GND      UP
GPIO4   ──┤ ├──── GND      SEL  (ОК, долго = ESC)
GPIO6   ──┤ ├──── GND      DOWN
```

| Кнопка | GPIO | Функция |
|---|---|---|
| **UP** | **GPIO5** | предыдущий пункт |
| **SEL** | **GPIO4** | ОК · долгое (>0.7 с) = назад/ESC |
| **DOWN** | **GPIO6** | следующий пункт |

* Внутренние **pull-up** включает прошивка — внешние резисторы **не нужны**.
* Кнопки замыкают GPIO на **GND**, без фиксации.
* Провода к кнопкам держите короткими (< 15 см) и подальше от антенны CC1101,
  иначе возможны ложные срабатывания при передаче.

Подробности и смена порогов — [BUTTONS.md](BUTTONS.md).

## 8. Порядок первого включения

### Прошивка готовым бинарником

В репозитории лежит собранная прошивка под эту конфигурацию —
[`firmware/Bruce-esp32s3-n16r8-st7735s.factory.bin`](../firmware/Bruce-esp32s3-n16r8-st7735s.factory.bin)
(4.1 MB, экран + 3 кнопки + CC1101 уже настроены).

Перевести плату в download mode (BOOT + RESET) и прошить в нулевой адрес:

```bash
esptool --chip esp32s3 --port COM3 --baud 460800 write_flash 0x0 \
  firmware/Bruce-esp32s3-n16r8-st7735s.factory.bin
```

Сборка из исходников — в [INSTALL.md](INSTALL.md).

### Пошагово

1. **Не подключая** дисплей, кнопки и CC1101 — подать питание на плату ESP32-S3
   от boost-преобразователя. Проверить мультиметром 3.3 V на `3V3`.
2. Подключить дисплей, прошить прошивку (download mode: BOOT + RESET, см.
   [INSTALL.md](INSTALL.md)). Проверить, что логотип появился.
3. Подключить кнопки, пройтись по меню вверх/вниз/ОК/ESC.
4. Подключить CC1101, выбрать `Sub-Ghz → RF Module → CC1101`.
   Убедиться, что ошибки `CC1101 not found` нет.
5. Прикрутить антенну. Только после этого запускать передачу.

### CC1101 не находится

| Проверка | Как |
|---|---|
| Питание 3.3 V на модуле | мультиметр VCC–GND CC1101 |
| MISO ↔ GPIO19, MOSI ↔ GPIO17, SCK ↔ GPIO18 | прозвонка |
| CSN = GPIO12, GDO0 = GPIO14 | прозвонка + `Settings → CC1101 Pins` |
| Общий GND платы и модуля | обязательно |
| Пины не заняты другим | `Settings → I2C Finder`, `Settings → Pins` |
| Провода короче 15 см | длинные провода на 27 МГц SPI не работают |

### Wi-Fi «отваливается» при передаче на 433 МГц

Аппаратная особенность ESP32: общий тракт 2.4 ГГц и соседние помехи.
Не используйте одновременную передачу Sub-GHz и Wi-Fi TX. Для записи пил
это не критично.

## 9. Потребление и автономность

| Режим | Ток (3.3 В) |
|---|---|
| Экран + idle, Wi-Fi выключен | ~45 мА |
| Wi-Fi сканирование | ~180 мА |
| Wi-Fi TX (деauth и т. п.) | ~350 мА пик |
| CC1101 RX | ~18 мА |
| CC1101 TX 10 dBm | ~60 мА |

LiPo 1000 мА·ч → примерно **3–5 часов** активной работы, **10–14 часов** в простое
с погасшим экраном.

## 10. Чего делать нельзя

* ❌ 5 V на `3V3`, на `VCC` дисплея, на `VCC` CC1101, на ноги кнопок.
* ❌ Подключать неподстроенный MT3608 к плате.
* ❌ Передавать на CC1101 без антенны.
* ❌ Вешать что-либо на GPIO26–37 (flash/PSRAM).
* ❌ Тронуть GPIO0/3/45/46 — плата не загрузится.
* ❌ Использовать GPIO15 как `SCL` для I2C — это сброс дисплея, экран погаснет.
